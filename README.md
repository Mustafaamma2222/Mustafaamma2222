# ميزانيتي الشهرية

موقع شخصي لتتبع الميزانية الشهرية: واجهة عربية كاملة (من اليمين لليسار)، وضع ليلي ونهاري، و**البيانات محفوظة في متصفحك فقط**. لا يوجد تسجيل دخول ولا خادم ولا قاعدة بيانات.

**الموقع المنشور:** https://mizaniyati-budget-ylh1.netlify.app

---

## المزايا

- **لكل شهر:** الراتب + المصاريف حسب الفئة (طعام، اشتراكات، ادخار، إنترنت) + فئات مخصصة.
- **كل شهر محفوظ لوحده:** تنقّل بين الأشهر، عدّل، احذف، وقارن.
- **تحليل كامل للشهر:** إجمالي المصاريف، المتبقي، مبلغ كل فئة ونسبتها من الراتب ومن المصاريف، والفرق مع الشهر السابق.
- **مخططات:** دائري (توزيع المصاريف)، أعمدة (مقارنة الفئات)، خطي (الاتجاه عبر الأشهر).
- **مقارنة أي شهرين** بجدول تفصيلي.
- **نسخة احتياطية:** تنزيل البيانات كملف JSON واستيرادها على أي جهاز أو متصفح.
- **أرقام وتحليل فقط** — بدون نصائح أو توصيات.

## أين تُحفظ البيانات؟

- في **localStorage** داخل المتصفح الذي تستخدمه. لا تُرسل لأي مكان.
- كل متصفح/جهاز له بياناته الخاصة. لنقلها: تبويب **الأشهر** ← **تنزيل نسخة** ثم **استيراد نسخة** في الجهاز الآخر.
- مسح بيانات المتصفح أو التصفح الخاص يحذفها، لذلك نزّل نسخة احتياطية بين فترة وأخرى.

## هيكل المشروع

```
public/
  index.html   الصفحة
  styles.css   التصميم (فاتح/داكن، متجاوب)
  app.js       المنطق والتخزين المحلي والمخططات
netlify.toml   إعدادات النشر (مجلد public بدون بناء)
```

## النشر على Netlify

- الموقع ثابت بالكامل: **Publish directory** = `public`، ولا يحتاج أمر بناء ولا متغيرات بيئة.
- للتحديث التلقائي عند كل رفع إلى GitHub: في Netlify افتح **Site configuration ← Build & deploy ← Link repository** واختر هذا المستودع والفرع.

## التشغيل المحلي

```bash
npm run dev    # يفتح على http://localhost:5173
```

أو افتح `public/index.html` مباشرة في المتصفح.
